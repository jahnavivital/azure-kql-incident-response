# Azure Log Analytics KQL Query Library for Incident Response

## Project Overview

This project provides a reusable Kusto Query Language (KQL) query library
for identifying and analyzing common incidents in Azure environments.

It combines KQL queries, log parsing, automated incident detection,
query optimization, incident summarization, and dashboard-ready data
to support faster incident response.

## Problem Statement

Large volumes of logs generated by applications and Azure services make
manual incident analysis time-consuming.

Different log formats make reliable parsing difficult, while processing
large datasets can increase query cost and analysis time.

This project provides reusable KQL queries and supporting tools to
identify common incident patterns and improve incident analysis.

## Objectives

- Build reusable KQL queries for common incident patterns.
- Reduce repetitive manual log analysis.
- Support faster incident diagnosis.
- Handle common unstructured log formats.
- Detect application and service failures.
- Detect authentication failures.
- Detect HTTP 5xx errors.
- Detect slow requests.
- Optimize queries for large datasets.
- Generate incident summaries and dashboard-ready data.

## Key Features

### 1. Reusable KQL Query Library

Provides ready-to-use queries for:

- Application errors
- HTTP 5xx errors
- Failed logins
- Slow requests
- Service failures

### 2. Log Parsing

The Python parser extracts useful information from unstructured log
messages, including:

- User
- IP address
- Duration
- Server
- Endpoint

### 3. Automated Incident Detection

The detection module identifies:

- Payment Timeout
- Database Failure
- Authentication Failure
- HTTP Failure
- Slow Request
- Critical Slow Request
- Database Resource Exhaustion

### 4. Severity Classification

Detected incidents are classified as:

- HIGH
- MEDIUM

### 5. Query Optimization

The optimized KQL query demonstrates:

- Early filtering
- Time-range restriction
- Selecting only required columns
- Aggregation after filtering

### 6. Incident Summary

The reporting module provides statistics by:

- Incident type
- Severity
- Service

### 7. Dashboard Data

Dashboard-ready JSON data provides:

- Total incidents
- Severity distribution
- Incident-type distribution
- Service-wise incident counts
