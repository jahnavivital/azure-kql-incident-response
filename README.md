# Azure Log Analytics KQL Query Library for Incident Response

## Project Overview

This project provides a reusable Kusto Query Language (KQL) query library
for identifying and analyzing common incidents in Azure environments.

The project aims to reduce incident diagnosis time by providing ready-to-use
queries for application errors, HTTP failures, authentication failures,
slow requests, and service failures.

## Problem Statement

Large volumes of logs generated by applications and Azure services make
manual incident analysis time-consuming. Different log formats and large
datasets can make it difficult to quickly identify the root cause of an
incident.

This project provides reusable KQL queries that help incident-response teams
search, analyze, and correlate Azure log data efficiently.

## Objectives

- Build reusable KQL queries for common incident patterns.
- Reduce incident diagnosis time.
- Analyze Azure logs efficiently.
- Identify application and service failures.
- Detect authentication failures.
- Detect slow requests.
- Optimize queries for large datasets.
- Provide structured documentation for incident response.
